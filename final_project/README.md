# GigaVibeMiptCode

Консольный ИИ-ассистент, написанный как итоговый проект по курсу Python.

По сути это чат-бот, который работает через OpenAI-совместимое API. Использована Ollama с моделью gemma3:4b.

## Что умеет

- **Чат с ИИ** -- обрабатывает пользовательский ввод, отправляет запрос к LLM через OpenAI compatible API и выводит ответ в консоль. Ответы приходят в стриминговом режиме.
- **Контроль длины контекста** -- хранит историю сообщений и передает её модели как контекст. Перед каждым запросом проверяет, что контекст не превышает лимитов по количеству сообщений (`limit_message`) и по суммарному количеству символов (`limit_chars`). Если превышает -- удаляет самые старые сообщения.
- **Конфигурирование** -- настройки задаются через `config.yaml` или переменные окружения. Переменные окружения имеют приоритет над yaml.
- **Прерывание запроса** -- во время ожидания ответа модели можно нажать Ctrl+C, чтобы прервать запрос и вернуться к вводу.
- **Прикрепление файлов** -- синтаксис `@::путь/к/файлу::` подставляет содержимое файла в сообщение. Максимальный размер файла 5 МБ, количество файлов не ограничено.
- **Обработка файла по частям** (`/file_chunk`) -- разбивает большой файл на куски (по абзацам или по количеству символов) и обрабатывает каждый кусок отдельно с заданным промптом.
- **Команды** -- `\q` для выхода, `/reset` для очистки истории и экрана.

## Запуск

```bash
git clone <url репозитория>
cd mipt_homeworks_sem2_2026
pip install openai pyyaml
ollama pull gemma3:4b
ollama serve
cd final_project
python Main.py
```

## Конфигурация

Файл `config.yaml`:

```yaml
api_key: ollama
api_host: http://localhost:11434/v1/
model: gemma3:4b
limit_message: 20
limit_chars: 4000
temperature: 0.7
system_prompt: "Ты дружелюбный ИИ-ассистент."
```

Или через переменные окружения:

```bash
export API_KEY=ollama
export API_HOST=http://localhost:11434/v1/
export LIMIT_CHARS=2000
python Main.py
```

Если нет ни переменных окружения, ни config.yaml -- программа выведет ошибку и завершится.

## Структура проекта

```
final_project/
    Main.py        -- основной код программы
    config.yaml    -- конфигурация
    ruff.toml      -- настройки линтера
    README.md      -- текущий файл
```

Весь код находится в одном файле `Main.py`. Классов нет, программа построена на функциях:

- `load_config()` -- загружает настройки из config.yaml и переменных окружения, возвращает словарь с параметрами.
- `trim_history()` -- обрезает историю сообщений по лимитам. Удаляет самые старые сообщения пока лимиты не будут соблюдены.
- `process_file_refs()` -- ищет в тексте паттерны `@::filepath::`, читает содержимое указанных файлов и подставляет его в сообщение.
- `send_message()` -- отправляет запрос к LLM через OpenAI клиент и выводит ответ в консоль.
- `get_model()` -- определяет какую модель использовать.
- `parse_file_chunk_args()` -- парсит аргументы команды `/file_chunk`.
- `split_into_chunks()` -- разбивает текст на куски.
- `file_chunk_mode()` -- режим обработки файла по частям.
- `main()` -- обрабатывает запрос пользователя и выдает ответ, вызывая нужные функции.
